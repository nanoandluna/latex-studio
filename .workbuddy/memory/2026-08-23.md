## GitHub 项目审查：overleafweb（LaTeX Studio）

对工作区 `D:\opencode\overleafweb` 做了一次只读审查（用户要求仅出结论、不改代码）。项目为 `latex-studio` v0.1.1，本地优先 LaTeX 工作区，React 18 + Fastify 5 + pnpm monorepo，MIT 协议。

### 关键结论
- **P0 高危**：`apps/server/src/app.ts:20` 的 CORS 配置为 `origin: true`（反射任意 Origin），服务监听 `127.0.0.1:3210`，任何网页可跨域调用本地 API 并读响应。叠加 `/api/workspace/open` 接受任意绝对路径（`workspaceService.open` 无白名单），构成「任意本地文件读取 + 写/删」攻击面（典型 localhost CSRF / DNS-rebinding）。
- **P1**：`errors.ts` 兜底分支回显 `e.message`（含内部文件系统路径）；`build.ts:92` 用 `message.includes('not available')` 字符串判错。
- **P1**：`build.ts:117-118` SyncTeX 路由 `safeResolve(...); void abs;` 校验结果被丢弃，依赖 `forwardSearch` 内部二次 resolve（当前被 safeResolve 抛异常兜住，但属反模式）。
- **P2**：`saveFile` 无 isTextFile 校验（与 createFile 不一致）；`BUILD_OUTDIR`/`BUILD_DIR_NAME` 常量重复；多处死代码 `void mainFile`/`void monaco`/`void abs`。
- **优点**：`safeResolve` 路径穿越防护完整且有单测；全程 `spawn({shell:false})` 无命令注入；构建隔离 `.build/` + `%PDF-` 魔数校验防 stale PDF；测试体系完善（8 个 vitest + Playwright 01-10 + real-LaTeX 门禁）。
