# V0.5.0 — Research Writing Workspace

> North star: **让研究生不是在"写 LaTeX"，而是在"管理一篇论文"。**
>
> Target user: 研究生/论文作者。IDE 层（编辑/编译/预览/安全）在 V0.4.2 已经足够强，
> 从本版本起不再堆底层设施，而是把 **Project Graph + Statistics + Diagnostics +
> Inspectors** 汇聚成用户一打开就能看懂的"论文驾驶舱"。
>
> Baseline: v0.4.2。`pnpm release:check` 全绿是每一项改动的前置条件。

## Scope lock

### Core P0（4 个模块，不多做）

1. **Paper Overview** — 论文驾驶舱：结构 / 内容 / 图表 / 引用 / 诊断一览 +
   按章分解。Project Graph 第一次变成用户可见的价值。
2. **Citation Workspace** — 论文文献工作区：All / Used / Unused / Undefined /
   Duplicate 分组 + 定义↔使用↔上下文贯通。**不做 BibTeX 编辑器**。
3. **Reading Workspace** — PDF 从"编译结果查看器"升级为"论文阅读器"：
   缩略图、Outline↔PDF 同步、阅读位置记忆与恢复。
4. **Terminology Consistency** — 用户自定义术语表（首选词/变体/缩写/禁用形），
   纯规则检测不一致并定位。**不用 AI。**

### Supporting（跟随 P0 顺手完成，不独立立项）

- **Paper Search → Context**：现有搜索结果附上 章节/Section 归属
  （如 `Chapter 3 / Method`），不重做搜索引擎。

### P1（P0 稳定后再做）

Citation Coverage · Figure/Table/Equation Coverage（按"定义/引用/未引用/缺失"
计数，不做单一 Health 分数）· Chapter Statistics 增强 · Reading History ·
中文界面 / i18n。

### V0.5.1 — Research Workflow Hardening

大型真实论文项目（多文件 \input 的跨文件章节归因）· BibLaTeX 边界 ·
统计口径正确性回归 · 术语表持久化 · 阅读状态恢复。

### 永久移出（继续砍）

AI · 云同步 · 协作 · Git UI · Zotero 客户端 · JabRef 替代品 · PDF 批注 ·
Visual Editor · Multi-user · Multi-workspace · 模板商城。

产品边界（不变式）：

```text
Zotero / JabRef   = 管"文献库"
LaTeX Studio      = 管"文献在论文里的使用"
```

# 1. Paper Overview

## 1.1 定位

打开项目后的一屏总览——不是工程面板的堆叠，而是"这篇论文现在什么状态"。
数据 100% 来自既有 Project Graph 与 Statistics，**零新增扫描**。

## 1.2 数据模型（`GET /api/paper/overview`）

```jsonc
{
  "structure": { "chapters": 5, "sections": 38 },
  "content":   { "cjkCharacters": 28421, "latinWords": 8932, "estimatedWords": 37353 },
  "assets":    { "figures": 42, "tables": 19, "equations": 86 },
  "references": { "citations": 217, "bibEntries": 324,
                   "undefinedCitations": 2, "undefinedReferences": 0 },
  "diagnostics": { "errors": 0, "warnings": 4, "infos": 2 },
  "chapters": [
    { "title": "绪论", "file": "main.tex", "line": 7,
      "cjkCharacters": 4892, "estimatedWords": 1200,
      "citations": 12, "figures": 3, "tables": 2, "equations": 4 }
  ]
}
```

- `undefinedCitations`：\cite 的 key 不在 bibEntries 集合中（按去重 key 计）
- `undefinedReferences`：\ref 的 key 不在 labels 集合中（按去重 key 计）
- 两者均为确定性计算，不做字符串匹配诊断文案

## 1.3 按章归因语义

- 与 `/api/statistics` 的章节区间完全一致：每章拥有
  `[line, 下一个 level≤ 自身的 section)` 半开区间，按文件切片。
- 引用/图表/公式条目按 `(file, line)` 落入所在区间；首个 section
  之前的内容（导言区）不归属任何章。
- **已知限制（记入 V0.5.1）**：跨文件 `\input` 的内容暂不计入所属章
  （与现有统计口径一致）；章节字数合计 ≤ 项目合计，不重复计数。

## 1.4 展示

- 入口：Navigator 头部「Overview」按钮（与 Stats 并列）+ Palette
  `Show Paper Overview`
- 面板：五段指标（Structure / Content / Assets / References / Diagnostics）
  + 按章行（字数 · 引用 · 图/表/公式），点击章节行跳转源文件
- Diagnostics 显示计数；详情仍在 Problems 面板，不重复展示

# 2. Citation Workspace

## 2.1 定位

升级现有 Citation Inspector：从"引用列表"变成"文献在论文里的使用工作区"。

## 2.2 分组

```text
All（全部出现过的 key）
Used   — key 既在 .bib 中、也在正文被 \cite
Unused — 在 .bib 中但从未被 \cite
Undefined — 被 \cite 但 .bib 中不存在（编译会出 [?]）
Duplicate — 同一 key 在多个 bib 条目中重复定义
```

## 2.3 条目详情

```text
smith2025
Smith et al. · 2025            ← 来自 BibEntry 的 author/year 字段
Used 7 times
First use: 3.2 Method          ← 最近的前序 section 归属
Other usages: 4.1 · 4.3 · 5.2
[Open Bib] [Open First Usage] [Show All Usages]
```

- "Open Bib" = 打开定义该 key 的 .bib 文件行
- 归属复用 Paper Overview 的章节区间（同一套 line-interval 工具）

## 2.4 不做

字段编辑、条目创建、.bib 写入、去重合并、DOI 解析。bib 文件是
Zotero/Better BibTeX 的输出物，本工作区只读。

# 3. Reading Workspace

## 3.1 PDF 缩略图

- PDF.js 已在包内：侧栏渲染页面缩略图（每页 canvas 低倍率渲染，懒加载）
- 点击缩略图跳页；当前页高亮

## 3.2 Outline ↔ PDF 同步

- Project Graph 的 sections 已含 (file, line)；通过 SyncTeX forward
  把 section 映射到 PDF 页码，生成 PDF 侧 Outline
- 点击 Outline 项 → PDF 跳页（复用现有 forward search 基建）

## 3.3 阅读位置

- 按 (workspaceId, mainFile, buildId) 记录最后页码，
  持久化于 `.latex-studio/cache/reading-state.json`（watcher 忽略区内）
- 打开 PDF 时提示/直接恢复 "Resume from page N"；
  换 workspace 或重建 build 后自然失效，不做迁移

# 4. Terminology Consistency

## 4.1 术语表

- 用户定义：Preferred term + Variants + Acronym + Forbidden forms
- 存储：`.latex-studio/terminology.json`（watcher 忽略区内，随 workspace 走）
- 结构：

```jsonc
{ "terms": [ { "preferred": "mmWave radar",
               "variants": ["millimeter-wave radar", "millimeter wave radar"],
               "acronym": "mmWave", "forbidden": [] } ] }
```

## 4.2 检测（纯规则）

- 扫描剥离注释后的正文，大小写不敏感的整词匹配 variants/forbidden
- 命中 → 诊断条目：`terminology inconsistency: "millimeter-wave radar" → mmWave radar`
  （file:line 定位，进 Problems 面板的 index 层）
- 检测时机：跟随现有索引刷新（节流，术语表变更时全量重算一次）

## 4.3 UI

- Navigator 新分组 "Terminology"：术语 + 命中数 + flag
- 术语表编辑：Settings/面板内小型行编辑（不改成大编辑器）

# 5. Paper Search → Context

- `/api/search` 结果条目新增 `section?: string`（所属最近前序 section 标题，
  复用章节区间）与 `chapter?: string`
- UI：搜索结果行在文件名下补一行灰字 `Chapter 3 / Method`
- 不改搜索算法、不改索引结构
