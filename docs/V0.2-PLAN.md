# V0.2 — LaTeX IDE Intelligence

> Theme: from "editor + compiler + viewer" to a **true LaTeX IDE**.
>
> Baseline: v0.1.1 (Release Gate all-PASS). Every V0.2 feature ships only when
> `pnpm release:check` stays green.

## Scope & Priorities

### P0 — SyncTeX bidirectional

Status: forward search (source → PDF) shipped in v0.1.0 behind Ctrl+Click.

- [ ] **Inverse search** (PDF → source): click/double-click a PDF location →
      open the source file at the mapped line.
  - Backend: `synctex edit -o "<page>:<x>:<y>:<pdf>"` parsing (`Input:` / `Line:` records).
  - Frontend: canvas click → convert client coords to PDF points (account for
    scale/rotation/devicePixelRatio) → POST `/api/synctex/inverse` → `openFileAtLine`.
  - Acceptance: E2E — build multi-file fixture, click a heading in the PDF,
    correct file+line opens; works at zoom ≠ 100% and rotation = 90°.
- [ ] Forward-search polish: highlight the target line region briefly after jump.
- [ ] SyncTeX availability surfaced in the env badge (currently silent no-op).

### P0 — Outline panel

- [ ] Parse sectioning commands (`\part \chapter \section \subsection
      \subsubsection \paragraph`, starred variants, optional TOC labels) from the
      active file and the whole project (toggle: File / Project scope).
- [ ] Left-dock panel below Explorer: indented tree, click → reveal line;
      live update on save (debounced parse of the open buffer first, disk second).
- [ ] Numbers shown as compiled (`1.1 Background`) via depth counting, not regex guesses.
- [ ] Acceptance: unit tests for the outline parser; UI test — edit a heading,
      outline updates after save.

### P0 — IntelliSense 2.0

Current completions are static-trigger based. Upgrade to context-aware:

- [ ] `\usepackage{}` completion from a bundled package database (~2k common
      packages w/ one-line descriptions), filtered by distribution detection later.
- [ ] `\documentclass{}` completion (article/report/book/beamer/ctexart/…).
- [ ] Environment-aware `\begin{}`/`\end{}` pairing: typing `\end{` offers only
      currently-open environments; auto-insert matching `\end{}` on newline.
- [ ] Project-derived completions stay live: bib keys, labels, graphics paths,
      plus NEW: custom macros defined via `\newcommand/\def/\NewDocumentCommand`
      in any project file (with their argument counts as snippets).
- [ ] Completion context index shared with Outline/Navigator (see Architecture).

### P1 — Project Navigator

Unified "everything in this paper" view:

```text
NAVIGATOR
▾ Sections      Introduction / Method / Experiment …
▾ Figures       fig:architecture · fig:result
▾ Tables        tab:benchmark · tab:hyperparams
▾ Equations     eq:loss
▾ Labels        sec:intro · app:prompts
▾ Citations     smith2025 · doe2024
```

- [ ] Backed by the same project index as Outline/completions (single scanner,
      multiple consumers — do NOT implement three separate file walkers).
- [ ] Click → jump; citation rows show entry title/year from parsed .bib.

### P1 — PDF reading experience

- [ ] Search upgrade: match across text-item boundaries (join adjacent items,
      handle hyphenation), current-match scroll-into-view on the page.
- [ ] Keep lazy rendering; add page-level cache eviction for >100-page docs.
- [ ] Thumbnail rail (optional, behind a toggle).

## Architecture groundwork

1. **Project Index Service** (`packages/latex-index`): one incremental scanner
   producing `{labels, citations, sections, macros, includes, packages}`;
   consumers = Outline, Navigator, IntelliSense, inverse-SyncTeX disambiguation.
   Replaces today's ad-hoc `collectBibKeys` / `collectLabels` / completion-context
   refreshes (audit items #2/#3) — invalidation on file save/create/delete/rename.
2. **Build progress channel**: SSE endpoint `/api/build/:id/stream` emitting
   phase events (starting → pass N → bibliography → done). Build API keeps its
   synchronous response for compatibility.
3. **doctor ↔ detector convergence**: keep doctor standalone-capable but extract
   the probe core into `packages/tex-probe` so both import it (audit item #8).

## Non-goals for V0.2
