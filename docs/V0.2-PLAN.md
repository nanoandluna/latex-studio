# V0.2 — LaTeX IDE Intelligence

> Theme: from "editor + compiler + viewer" to a **research-ready LaTeX IDE** —
> let users actually write a paper with it.
>
> Baseline: v0.1.1 (Release Gate all-PASS). Every V0.2 feature ships only when
> `pnpm release:check` stays green.

## Core architecture decision

One **Project Index** feeds everything:

```text
            Project (.tex / .bib / figures)
                        │
                 ┌──────┴──────┐
                 │ ProjectIndex│   packages/latex-index
                 └──────┬──────┘
        ┌───────────────┼────────────────┐
        ▼               ▼                ▼
     Outline         Navigator      IntelliSense
        │               │                │
     Editor          Explorer         Monaco
                        │
                     SyncTeX
                        │
                      PDF
```

A single incremental scanner produces
`{sections, labels, citations, figures, tables, equations, macros, includes,
packages}`; Outline, Navigator and IntelliSense are all consumers of this index.
It replaces today's ad-hoc `collectBibKeys` / `collectLabels` /
completion-context refreshes, invalidated on file save/create/delete/rename.

## Scope & Priorities

### P0 — SyncTeX bidirectional

Status: forward search (source → PDF) shipped in v0.1.0 behind Ctrl+Click.

- [ ] **Inverse search** (PDF → source): click/double-click a PDF location →
      open the source file at the mapped line.
  - Backend: `synctex edit -o "<page>:<x>:<y>:<pdf>"` parsing (`Input:` / `Line:` records).
  - Frontend: canvas click → convert client coords to PDF points (account for
    scale/rotation/devicePixelRatio) → POST `/api/synctex/inverse` → `openFileAtLine`.
  - Acceptance: E2E — build multi-file fixture, click a heading in the PDF,
    correct file+line opens; works at zoom ≠ 100% and rotation = 90°.
- [ ] Forward-search polish: highlight the target line region briefly after jump.
- [ ] SyncTeX availability surfaced in the env badge.

### P0 — Outline / Structure panel

- [ ] Parse sectioning commands (`\part \chapter \section \subsection
      \subsubsection \paragraph`, starred variants) — File scope and Project scope toggle.
- [ ] Left-dock panel below Explorer: indented tree with compiled numbering
      (`1.1 Background`), click → reveal line; live update on save (debounced).
- [ ] Backed by the Project Index, not a separate parser.
- [ ] Acceptance: unit tests for the outline parser; UI test — edit a heading,
      outline updates after save.

### P0 — Project Index (`packages/latex-index`)

- [ ] Incremental scanner API: `index(projectRoot) → ProjectIndex`, plus
      `update(file, content)` for single-file invalidation.
- [ ] Producers: structure parser, label parser, citation parser, graphics
      parser (`\includegraphics` targets), package parser (`\usepackage`),
      macro parser (`\newcommand/\def/\NewDocumentCommand`), include graph.
- [ ] Consumers: Outline, Navigator, IntelliSense, inverse-SyncTeX
      disambiguation, and (V0.4) AI project context.

### P0 — Project Navigator

```text
NAVIGATOR
▾ Sections    Introduction · Method · Experiment …
▾ Figures     fig:architecture · fig:result
▾ Tables      tab:benchmark
▾ Equations   eq:loss
▾ Citations   smith2025 · doe2024
▾ Labels      sec:intro · fig:architecture
```

- [ ] Unified view over the whole project; click → jump to definition/source.
- [ ] Citation rows show title/year from parsed `.bib`.

### P1 — Context-aware IntelliSense 2.0

- [ ] `\usepackage{}` completion from a bundled package database (~2k common
      packages with one-line descriptions).
- [ ] `\documentclass{}` completion.
- [ ] Environment-aware pairing: `\end{}` offers only currently-open
      environments; newline inside `\begin{}…` auto-inserts `\end{}`.
- [ ] Custom macros from any project file offered as snippets with argument hints.
- [ ] All project-derived completions served from the Project Index.

### P1 — PDF reading experience

- [ ] Search upgrade: match across text-item boundaries (adjacent item joining,
      hyphenation), current-match auto scroll-into-view.
- [ ] Keep lazy rendering; add page-cache eviction for >100-page documents.

### P1 — Image preview

- [ ] Double-click `png/jpg/jpeg/svg/pdf` in the tree → inline viewer tab
      instead of nothing.

## Explicitly deferred

| Item | Target |
| --- | --- |
| Bib **Intelligence** (hover cards, missing-citation diagnostics) | V0.3 |
| Templates | V0.3 |
| Git / snapshots / history | V0.5 |
| **AI** (error-fix, rewrite, explain, generate — driven by Project Index) | **V0.4** |
| Spell/grammar checking | unscheduled |

Rationale: V0.2 builds the understanding layer (Project Index). AI on top of an
index-aware IDE ("check chapter 3 for references to non-existent figures") is
worth 10× a chat sidebar bolted onto raw text — so AI moves up to V0.4, after
Research Workspace (V0.3), not V0.6.

## Release criteria

- All P0 items implemented + tested; `pnpm release:check` green on Windows.
- New fixtures: synctex-inverse mapping corpus, macro-definition project.
- Version tag `v0.2.0` + GitHub Release notes listing the gate table.
