# V0.3 — Research Workspace Intelligence

> Theme: from "understands LaTeX code" (V0.2) to **"understands a paper
> project"**. The Project Graph becomes the core; inspectors and diagnostics
> are its first consumers.

Baseline: v0.2.3 (Compatibility Final, Release Gate all-PASS).
`pnpm release:check` must stay green for every V0.3 change.

## Sequencing decisions (locked)

1. **Project Graph + File Watcher + Inspectors + Diagnostics first** —
   persistent disk cache is deferred to V0.3.1: the in-memory index rebuilds
   in well under a second even at 240 chapters, so a cache system would add
   staleness risk before proving watcher→increment→graph stability.
2. **Recent-projects list ships before any multi-workspace work** — the
   single-active-workspace architecture stays intact.
3. **Rule-based writing checks before AI** — AI lands in V0.4 standing on
   this graph, not as a chat sidebar.
4. **SyncTeX gains diagnostics only** (no new sync features): surface
   mapping availability/failure reasons (`.synctex.gz` missing, `.busy`
   leftovers, version mismatch) so inverse jumps never fail silently.

## P0 — Project Graph (`packages/latex-index`, new package or major latex-parser extension)

Unifies today's `includes` array into a first-class graph:

```text
            main.tex
               │
   ┌───────────┼───────────┐
   ▼           ▼           ▼
intro.tex  method.tex  result.tex
               │
        ┌──────┼──────┐
        ▼      ▼      ▼
  fig:frame  eq:loss  tab:conf
        │
        ▼
    refs.bib (citation edges)
```

- Node kinds: file · section · label · figure · table · equation · bibentry.
- Edge kinds: includes · references · cites · defines · uses-graphic.
- API: `graph.query(node) → { definition, uses[], file? }`,
  `graph.broken() → edges pointing at nothing`.

## P0 — File Watcher

- Watch only user sources: `.tex .bib .cls .sty .tikz` plus project asset dirs.
- Explicit separation at design time:
  ```text
  SOURCE_ROOT    = workspace (user files)
  BUILD_ROOT     = .build/            ← never indexed/watched
  IGNORED        = .latex-studio/ node_modules/ hidden/
  ```
- **Security (first-class)**: reject symlink/junction/reparse-point entries
  from the walk and from include resolution; dedicated filesystem-boundary
  tests on Windows junctions and POSIX symlinks (see review guidance).
- External-editor saves trigger incremental re-index through the same
  mtime-keyed path used by buffers.

## P0 — Inspectors (UI over the graph)

| Inspector | Shows |
| --- | --- |
| Figure | definition location · caption · graphic file · all `\ref` sites |
| Table | definition · caption · `\ref` sites |
| Citation | author/year/title · usage count · undefined/unused flags |
| Reference | definition(s) · every usage site |

All four are read-only views of `graph.query()`; click-through opens the
source line.

## P0 — Project Diagnostics ("Research Health")

One-click analyze producing:

```text
Errors              n
Warnings            n
Undefined refs      n
Duplicate labels    n
Undefined citations n
Unused citations    n      (in .bib but never \cite'd)
Unused labels       n      (defined but never \ref'd)
Missing graphics    n      (\includegraphics target absent)
Broken includes     n
```

Rendered in Problems with a summary header; optional health score later.

## P1 — Academic-writing checks (rule-based, local only)

- Inconsistent spelling variants (e.g. "millimeter wave" vs "millimetre-wave").
- Hedging/colloquial phrase warnings with suggestions.
- Paragraph-without-citation heuristic for Related Work sections.
- All rules offline, configurable per project (`.latex-studio/writing.json`).

## P1 — Recent projects

Persisted recent-workspace list in the open dialog; single active workspace
unchanged.

## P1 — Template packages

Templates as data packages (`templates/<id>/template.json` + files), not
hardcoded React: builtin set (article/report/beamer/ctexbook thesis) plus a
loadable community directory.

## Deferred / explicit non-goals

- Persistent disk index cache → **V0.3.1**
- Multi-workspace → unscheduled
- Git/snapshots → V0.5
- AI → V0.4

## Release criteria

- All P0 items shipped with tests (watcher boundary tests included);
  `pnpm release:check` green on Windows.
- New fixtures: symlink/junction boundary corpus; watcher external-save case.
- Tag `v0.3.0` + GitHub Release with gate table.
